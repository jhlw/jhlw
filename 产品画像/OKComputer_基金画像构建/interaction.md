# 基金产品画像系统交互设计

## 核心交互功能

### 1. 智能基金筛选器
- **位置**: 主页面左侧筛选面板
- **功能**: 多维度筛选条件
  - 基金类型：股票型、债券型、混合型、货币型、指数型
  - 风险等级：低风险、中低风险、中风险、中高风险、高风险
  - 收益范围：年化收益率区间选择器
  - 基金规模：基金资产规模区间选择器
  - 成立时间：基金成立时长选择器
- **交互**: 实时筛选，选择条件后立即更新右侧基金列表
- **可视化**: 筛选条件以标签形式展示，支持一键清除

### 2. 基金产品对比工具
- **位置**: 基金列表页面，支持多选对比
- **功能**: 
  - 最多支持4只基金同时对比
  - 对比维度：基本信息、业绩表现、风险指标、持仓结构、费用对比
- **交互**: 
  - 点击基金卡片上的"添加对比"按钮
  - 在对比面板中查看详细对比结果
  - 支持移除对比基金，添加新基金
- **可视化**: 雷达图展示综合对比，表格形式展示详细数据差异

### 3. 动态业绩分析图表
- **位置**: 基金详情页面和分析页面
- **功能**:
  - 收益走势：支持1月、3月、6月、1年、3年、5年时间维度
  - 风险指标：夏普比率、最大回撤、波动率趋势图
  - 业绩排名：同类基金排名变化趋势
  - 持仓分析：股票持仓行业分布饼图，重仓股柱状图
- **交互**: 
  - 时间轴滑动选择查看不同时期数据
  - 图表类型切换（线图、柱状图、饼图）
  - 数据点悬停显示详细信息
- **可视化**: 使用ECharts实现专业级金融图表

### 4. 风险评估矩阵
- **位置**: 风险评估页面
- **功能**:
  - 风险-收益散点图：横轴为风险（波动率），纵轴为收益
  - 基金分布在不同风险收益象限
  - 支持按基金类型、规模、成立时间筛选
- **交互**:
  - 点击散点查看基金详细信息
  - 拖拽选择区域查看该区域内基金统计
  - 缩放和平移查看详细分布
- **可视化**: 散点图颜色编码表示不同基金类型，大小表示基金规模

## 用户交互流程

### 主要使用场景
1. **基金筛选流程**: 用户进入首页 → 设置筛选条件 → 查看筛选结果 → 选择感兴趣基金 → 查看详细信息
2. **基金对比流程**: 用户选择多只基金 → 进入对比页面 → 查看多维度对比 → 导出对比报告
3. **业绩分析流程**: 用户搜索特定基金 → 查看业绩走势 → 分析风险指标 → 查看持仓结构 → 做出投资决策
4. **风险评估流程**: 用户进入风险页面 → 设置评估参数 → 查看风险矩阵 → 识别合适风险等级基金

### 交互反馈机制
- **实时搜索**: 输入基金名称时实时显示匹配结果
- **加载状态**: 数据加载时显示专业loading动画
- **操作确认**: 重要操作（如清空筛选条件）需要二次确认
- **数据导出**: 支持导出PDF报告和Excel数据表
- **收藏功能**: 支持收藏感兴趣的基金，便于后续查看

## 响应式设计考虑
- **桌面端**: 充分利用屏幕空间，多列布局展示更多信息
- **平板端**: 适配中等屏幕，保持核心功能可用性
- **移动端**: 简化界面，重点突出核心数据和操作按钮
