# 产品画像（产品谱系与产品画像子项目）

基金公司产品主数据标准的领域上下文：产品谱系、产品画像、公司画像与视图的术语与规则。设计规格见 `docs/superpowers/specs/2026-08-14-产品谱系与产品画像-design.md`。

## 谱系

**产品谱系**:
公司产品版图的三层分类树（产品线 → 产品族 → 产品），回答"产品属于哪里"。
_Avoid_: 产品分类体系、产品树

**产品线**:
按投资策略与目标客群划分的一级分类；公募初始六线：现金管理、固定收益、混合配置、权益投资、指数增强、养老目标。归属冲突时资格识别优先（养老目标基金资格进养老线），裁决结果入谱系案例库。
_Avoid_: 产品大类、业务线

**产品族**:
产品线内共享同一投资策略内核的产品系列。入族三条件同时满足：同一策略标签 + 同一业绩比较基准（体系一致）+ 同一投研团队；团队拆分或基准重大变更触发族重组评审。
_Avoid_: 产品系列、策略组

**产品**:
单只公募基金，必须且只能挂靠一个产品族。
_Avoid_: 基金、产品个体

**谱系编码**:
产品线 2 位 + 产品族 2 位共 4 位编码；私募资管/专户预留独立编码段（`2x`/`3x` 起）；编码由产品部统一分配，不回收复用。
_Avoid_: 分类码

**产品类别标记**:
产品族节点上的标记（公募 / 私募资管 / 专户），参与视图权限控制，私募画像仅授权人员可见。
_Avoid_: 产品类型

**换族**:
产品的谱系挂靠变更。需评审并永久留痕（生效日、原因、评审编号），业绩考核按归属时段分段计算。
_Avoid_: 改挂、调线

**监管分类**:
产品的法定分类属性（股票型 / 债券型 / 混合型 / 货币型 / QDII / FOF），与谱系并存：谱系管"公司怎么看产品"，监管分类管"报送怎么报产品"。
_Avoid_: 基金类型

## 画像

**画像模板**:
字段定义与元数据标准（7 项元数据：字段名、业务定义、数据类型、枚举值、必填性、来源与维护、适用视图），回答"画像能描述什么"，不含产品数据。
_Avoid_: 字段字典、数据标准

**产品画像**:
画像模板 × 具体产品的字段值实例，回答"这个产品怎么样"；通过谱系编码字段挂靠到谱系树节点。
_Avoid_: 产品档案（"产品档案"是内部视图的呈现形态）

**公司画像**:
公司全景信息（基本情况、经营概况、业绩同业、销售渠道、旗舰产品、客户结构、规模趋势、关系联动 8 块），回答"这家公司怎么样"，位于层级最上层。
_Avoid_: 管理人概况、公司简介

**双层画像**:
公司画像在上、产品画像在下的组合结构；销售输出时"公司速览 + 产品速览卡"组合呈现。
_Avoid_: 两层画像

**视图**:
主数据字段的投影，不存数据副本。销售视图按"产品速览卡"组织，内部视图按"产品档案"组织。
_Avoid_: 展示层、报表

**黑名单字段**:
仅内部视图可见的敏感字段（客户结构明细、渠道业绩、内部考核数据）。字段边界规则：默认双视图可见 + 黑名单例外。
_Avoid_: 敏感字段

**谱系覆盖度**:
已启用产品族数 ÷ 公司产品版图目标族数；空白产品线/族清单是未来产品布局的候选方向，目标版图由产品部在年度产品规划中评审维护。
_Avoid_: 谱系完整性

**旗舰产品**:
年度评选的每线代表产品。量化标准：同类规模前 3 名或近 3 年区间收益率同类前 25%（累计净值口径），每产品线至多 2 只；明星产品可由产品部提名例外进入（风控确认业绩口径）。
_Avoid_: 重点产品、明星产品（"明星产品"是例外提名的一种依据）

## 口径

**累计净值口径**:
所有收益率字段的统一计算口径；禁止在画像中出现复权/分红另口径数据。
_Avoid_: 复权口径、分红再投资口径

**同业比较口径**:
同类产品定义默认采用银河证券分类；需用晨星口径时须在字段中注明所用体系，不得混用。
_Avoid_: 排名口径
