# Page Override: benchmark-query（s1 业绩基准及净值增长率查询）

> 覆盖 MASTER.md 的同名规则；适用于 s1 及 s3 类查询页。

- **首屏即数据**：无 hero，进页面直接渲染筛选条＋表格（默认今日批次＋全量历史、净值日期倒序）
- **列规格**：勾选列 32px 固定左；日期/代码列 Fira Code 12px；收益率列右对齐 `.num`；折算展示列与原始列用字重区分（折算列 500、原始 400）
- **分页**：服务端分页；673k 行级表（s3）页码跳转输入框必备，仅上一页/下一页不够用
- **批量导出**：勾选 ≥1 行才显示动作条（「导出所选 N 条」）；导出中按钮 loading，完成后 toast 可撤销区不必需，但需文件名可见
- **排序**：表头点击排序，当前列显示 ▲▼ 形状指示（不只变色）
- **空态**：筛选后无结果给「重置筛选」出口按钮
- **可选趋势视图**：切换按钮进入折线图（MASTER §Charts 规则），图下方保留数据表切换出口
