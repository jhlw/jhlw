# Page Override: config-approval（发起/审核双面板弹层族）

> 适用于 UC-004/005 配置发起与删除、UC-007 行情维护三弹层——共享同一审批骨架。

- **骨架**：弹层宽 640–900px；顶部页签 ①发起面板 ②审核面板；页签是**状态指示器**（当前步骤实心、未达步骤灰色禁用态），不是自由切换——审核面板仅在提交发起后可进入
- **发起面板**：表单纵向流，标签右缘对齐 96–130px；行编辑表格（添加行/删除行）放主区；权重合计/校验信息**就近**置于合计行，不汇总到弹层顶部
- **提交发起**：按钮走 Loading→「已提交，待审核」状态迁移，同时页签②点亮；草稿保存为次按钮（不抢主操作）
- **审核面板**：变更快照三列表（字段/变更前/变更后），差异行 `#FFFBEB` 底强调；动作固定右下的 退回修改（次）/ 审核通过（主，destructive 流程用红）
- **退回路径**：退回必须附意见（textarea 必填校验），回发起面板后意见条常驻顶部
- **紧急程度**：select 旁即时说明文案；紧急批次提交后列表徽标加 ● 前缀（色+形+文字）
- **键盘**：Esc 关闭发起面板前二次确认（有未提交行时）；页签/表格行可 Tab 到达
