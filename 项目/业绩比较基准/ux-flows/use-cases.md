# 用例清单（Use Cases）— 业绩比较基准管理系统

> 来源材料：`界面原型/业绩比较基准管理系统-界面原型.html`（结构提取）＋《业绩比较基准收益率统一计算与披露业务解决方案 v2.5》§5.1/§5.2 界面规格。
> 本文档为 ux-flow-designer Phase 1 产物，经确认后进入 Phase 2（Mermaid 图）→ Phase 3（可点击线框）→ Phase 4（交接文档）。
> 适配说明：原型为**桌面后台系统**（1280px、侧边导航），线框阶段将桌面视口替代技能默认的移动端 375px/Tab 栏，其余方法论不变。

## 角色

| 角色 | 职责 |
|------|------|
| 业务查看者 | 查询/导出基准收益率与净值增长率、基准行情（只读） |
| 经办（投资风险部） | 维护指数库、发起基准配置/删除、发起行情维护与批量导入 |
| 审核（投资风险部） | 对经办提交的配置、删除、行情维护单进行通过/退回 |
| 系统 | 估值系统净值增长率透传、指数类型自动识别、外盘币种反显、配置变更触发历史追溯重算 |

---

## UC-001 业绩基准及净值增长率查询

| 字段 | 内容 |
|------|------|
| ID | UC-001 |
| 名称 | 业绩基准及净值增长率查询 |
| 参与者 | 业务查看者 |
| 前置条件 | 基准日收益率已统一口径计算入库；估值系统净值增长率已透传 |
| 主流程 | 1. 进入「业绩基准及净值增长率查询」（默认今日及历史全量，按净值日期倒序） 2. 输入基金代码/日期范围筛选 3. 查询并分页浏览（基准逐日收益率、净值增长率、折算展示列） 4. 勾选目标行 5. 导出 |
| 替代流程 | 4a. 重置筛选条件回默认；3a. 无结果时显示空态 |
| 后置条件 | 无数据变化（只读查询） |

## UC-002 指数库维护

| 字段 | 内容 |
|------|------|
| ID | UC-002 |
| 名称 | 指数库维护（新增/编辑/详情/删除） |
| 参与者 | 经办（投资风险部） |
| 前置条件 | 拥有数据与配置维护权限 |
| 主流程 | 1. 进入「指数库维护」检索指数 2. 新增：填写指数名称与编码（Wind 代码为唯一键）→ 系统自动识别类型 → 数据源类指数经「选择数据源指数」弹层关联，外盘自动反显币种 3. 保存入库 4. 后续可打开详情、编辑、删除 |
| 替代流程 | 2a. 编码重复：唯一键校验拦截并提示修正；4a. 删除已被产品基准配置引用的指数：确认弹层警示 |
| 后置条件 | 指数记录更新，供应产品基准配置选用 |

## UC-003 产品基准配置查询与详情

| 字段 | 内容 |
|------|------|
| ID | UC-003 |
| 名称 | 产品基准配置查询与详情 |
| 参与者 | 业务查看者、经办 |
| 前置条件 | 存在版本化的基准配置（生效起止区间） |
| 主流程 | 1. 进入「产品基准配置管理」检索产品 2. 查看配置详情（成分基准、权重、生效区间、版本号） 3. 从详情跳转发起修改（衔接 UC-004）或删除（衔接 UC-005） |
| 替代流程 | 2a. 同一产品多版本并存：按生效区间标识当前有效版本 |
| 后置条件 | 无数据变化（详情只读，变更走发起/审核流程） |

## UC-004 发起基准配置（经办→审核）

| 字段 | 内容 |
|------|------|
| ID | UC-004 |
| 名称 | 发起基准配置变更（新增/修改） |
| 参与者 | 经办（发起面板）、审核（审核面板） |
| 前置条件 | 产品已入库；成分基准已在指数库维护 |
| 主流程 | 1. 点击「发起基准配置」打开弹层（默认发起面板） 2. 选择产品、配置成分基准与权重（合计必须 = 100%）、设定生效起止区间 3. 提交发起 4. 切换审核面板：审核查看变更快照 5. 审核通过 → 配置生效，系统触发历史追溯重算 |
| 替代流程 | 2a. 权重合计 ≠ 100%：前端校验拦截，不允许提交；5a. 审核退回 → 回到发起面板修改后重新提交 |
| 后置条件 | 新版本配置生效（版本化，旧版本保留区间记录）；变更后历史序列按新基准追溯重算 |

## UC-005 删除基准配置（经办→审核）

| 字段 | 内容 |
|------|------|
| ID | UC-005 |
| 名称 | 删除基准配置 |
| 参与者 | 经办、审核 |
| 前置条件 | 目标配置存在 |
| 主流程 | 1. 在列表点击删除，打开「删除基准配置」弹层（发起面板） 2. 确认删除对象与理由，提交发起 3. 审核面板：审核确认 4. 通过 → 配置删除 |
| 替代流程 | 4a. 退回 → 保留配置，流程结束 |
| 后置条件 | 配置删除或原样保留 |

## UC-006 基准行情查询（只读）

| 字段 | 内容 |
|------|------|
| ID | UC-006 |
| 名称 | 基准行情查询 |
| 参与者 | 业务查看者 |
| 前置条件 | 行情维护单已审核通过入库 |
| 主流程 | 1. 进入「基准行情查询」 2. 切换指标视角：指数收盘点位 / 利率 / 汇率 3. 按 Wind 代码（唯一键）与日期检索 4. 分页浏览 |
| 替代流程 | 3a. 重置条件；无数据显示空态 |
| 后置条件 | 无数据变化（只读） |

## UC-007 基准行情维护（经办→审核，含批量导入）

| 字段 | 内容 |
|------|------|
| ID | UC-007 |
| 名称 | 基准行情维护（指数点位 / 利率 / 汇率） |
| 参与者 | 经办、审核 |
| 前置条件 | 指数/指标已在指数库维护 |
| 主流程 | 1. 进入「基准行情维护」选择维护类型 2. 打开对应弹层（收盘点位/利率/汇率），逐行添加数据或经「批量导入」下载模板→上传文件→执行导入 3. 设定紧急程度 4. 提交发起 5. 审核面板通过 → 数据入库，衔接 UC-001/UC-006 可查 |
| 替代流程 | 2a. 行级删除修正；4a. 审核退回 → 经办重新发起 |
| 后置条件 | 行情数据入库，参与基准收益率统一计算 |
