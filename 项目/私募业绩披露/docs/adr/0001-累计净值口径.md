# 收益率以累计净值口径计算

建行通知要求收益率「按照估值表数据计算」，但未指明净值口径。我们决定：**所有收益率（涨跌幅、成立以来年化收益率）均以累计净值计算**，报送编码用复权类型 `YieldType=6/5`。定案于 2026-08-14 的 grill-with-docs 会话。

**Status**: accepted

**Considered Options**:

- **单位净值**：产品分红会被误算为下跌，渠道展示产生伪回撤 → 拒。
- **复权净值（分红再投资）**：数学上最精确，但估值表不直接提供、需自建复权因子，且与渠道现有展示习惯不一致 → 拒。
- **累计净值**：估值表直接可得；分红已加回（不产生伪回撤，但不含再投资收益）；与银行渠道展示习惯一致 → 选。

**Consequences**:

- 有分红产品的涨跌幅报送 `YieldType=6`（复权语义），年化报送 `5`；无分红产品与 `2/1` 数值相同。
- 建行按净值数据自行生成涨跌幅曲线——其口径是否同为累计净值需确认（确认清单 C5）。
- 若建行未来要求分红再投资口径，需双方系统改造（确认清单 C7）。
