# R2 代销链 · 三栏例子表

> **用途**：R2 的活文档起点。来源：需求分析课 0003（tech/需求分析），**产品代码与数字为示意，待换当月真实管理费表数**。与 [R1-直销链-例子表.md](R1-直销链-例子表.md)、[R3-混合链-例子表.md](R3-混合链-例子表.md) 配套，待确认汇总见 [例子表-待确认汇总.md](例子表-待确认汇总.md)。

## 规则原文

> R2 代销：管理费表筛选**销售商名称＝建设银行**，名称拆分**保留地名**，按产品分组计算组内各地区管理费占比。（剩余份额分配算法 · 代销链，需求 xlsx「处理规则」sheet）

配套口径：
- **Q14**：比例保留 4 位小数，尾差计入占比最大方
- **C2**：代销渠道清单初始值「当前仅建设银行」——筛选步的等号眼下只认这一家

与 R1 的结构差异：R1 的地区是现成字段；R2 的地区藏在销售商名称里，前处理两道——**筛选**（名称＝建设银行）＋**拆分**（保留地名）。
