# 银行部拆分：总部份额可设置，剩余份额按数据规则计算

专户 KPI 净收入拆分中，银行部产品的部门内比例在需求原文（xlsx C5「银行部根据客户管理需求调整归属及比例」）与流程稿（xmind「比例根据产品实际销量及管理费计算所得」）之间存在矛盾。经 2026-09-08 需求拷问定稿：采用混合模型——银行业务部仅设置**归属银行总部的比例**（每月可调，即银行部的部门内调整），剩余比例（1 − 总部份额）按分行数据占比（销量/管理费）经「分行→分公司映射」自动分配至各分公司，分公司间分配无人工干预。

## Considered Options

- **全手工**（xlsx 原义、现状人工打标签）：分公司间分配也由银行部逐产品手工调整——被否，月度数据量大且销量/管理费数据已足以支撑自动计算。
- **全纯计算**（含总部份额 = 柜台管理费占比）：总部份额完全由数据推导——被否，总部份额承载客户管理诉求（xlsx C5 的原意），需保留人工抓手。

## Consequences

- xmind 中混合产品「直销总占比 × 直销内占比 + 代销总占比 × 代销内占比」公式作废（B 口径下直销不经分行，「直销内分公司占比」无数据来源），计入勘误。
- 银行部的月度「调整」收敛为单一参数：总部比例；设置界面展示「柜台管理费/总管理费」占比作为参考值，不自动采用（Q28 定稿）。
- 分行→分公司映射、代销渠道清单等主数据由银行业务部维护。
