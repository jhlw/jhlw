# R6 总部份额 · 三栏例子表

> **用途**：R6 的活文档起点。六条规则的收官表，也是**首张含「已定稿」行**的例子表（锁定 ADR-0001 口径，防回归）。**数字为示意，待换真实数**。配套：[R1](R1-直销链-例子表.md) / [R2](R2-代销链-例子表.md) / [R3](R3-混合链-例子表.md) / [R5](R5-匹配拆分-例子表.md)，待确认汇总见 [例子表-待确认汇总.md](例子表-待确认汇总.md)。

## 规则原文

> R6 总部份额：银行部**每月设置**总部份额（界面展示柜台占比参考值，**不自动采用**）；R1–R3 算得的地区占比**×（1−总部份额）**分配至分公司。（目标系统模型 · Q30 融合，需求 xlsx「处理规则」sheet）

已定稿口径（[ADR-0001](adr/0001-银行部拆分-总部份额可设置剩余纯计算.md)，2026-09-08 拷问定稿）——**不需要再问**：
- 总部份额每月可设可调，承载客户管理诉求（C5 原意），保留人工抓手
- 界面柜台占比只是参考值，**不自动采用**
- 分公司间分配纯计算，无人工干预

结构要点：R6 是六条规则里唯一带**人工参数**的——参数有人设，就有人忘设、设错粒度、设到端点。边界主力是「参数生命周期」，不是除法或匹配。
