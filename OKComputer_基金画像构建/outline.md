# 基金产品画像系统项目概述

## 项目目标
构建一个专业的基金产品画像分析系统，为公司内部提供全面的基金产品评价、筛选、对比和风险评估工具。

## 系统架构

### 页面结构
1. **index.html** - 主页面/仪表板
2. **analysis.html** - 基金分析页面
3. **compare.html** - 基金对比页面
4. **risk.html** - 风险评估页面

### 核心功能模块

#### 1. 主页面 (index.html)
**功能概述**: 系统入口，展示基金市场概览和核心功能

**主要组件**:
- 导航栏：系统Logo + 主要页面链接
- Hero区域：专业背景图像 + 系统介绍
- 基金筛选器：左侧筛选面板
  - 基金类型选择器
  - 风险等级滑块
  - 收益范围选择器
  - 基金规模过滤器
  - 成立时间筛选
- 基金列表展示：右侧主要区域
  - 基金卡片网格布局
  - 每个卡片显示：基金名称、类型、最新净值、日涨跌幅、年化收益
  - 快速操作按钮：查看详情、添加对比、收藏
- 市场概览仪表板：顶部统计卡片
  - 市场总览数据
  - 热门基金排行
  - 行业分布统计

**交互功能**:
- 实时筛选：选择条件后立即更新基金列表
- 搜索功能：按基金名称或代码搜索
- 排序功能：按收益率、风险等级、规模排序
- 分页加载：支持大量基金数据分页显示

#### 2. 基金分析页面 (analysis.html)
**功能概述**: 单只基金的详细分析和数据可视化

**主要组件**:
- 基金基本信息卡片：顶部展示区域
  - 基金名称、代码、类型、管理人
  - 最新净值、日涨跌幅、规模、成立日期
- 业绩分析图表区域：
  - 收益走势图：支持多时间维度切换
  - 同类对比图：与同类基金和基准指数对比
  - 风险指标图：夏普比率、最大回撤、波动率
- 持仓分析：
  - 行业分布饼图
  - 重仓股排行榜
  - 债券持仓结构（如适用）
- 基金经理信息：
  - 经理简介、从业年限
  - 管理基金数量、规模
  - 投资风格和理念

**数据可视化**:
- 使用ECharts实现专业级图表
- 支持图表类型切换和数据钻取
- 响应式图表设计，适配不同屏幕

#### 3. 基金对比页面 (compare.html)
**功能概述**: 多只基金的横向对比分析

**主要组件**:
- 对比基金选择器：
  - 最多支持4只基金同时对比
  - 搜索添加基金功能
  - 已选基金管理（移除、替换）
- 对比结果展示：
  - 基本信息对比表
  - 业绩指标对比雷达图
  - 风险收益散点图
  - 费率对比柱状图
- 详细对比分析：
  - 持仓结构对比
  - 投资策略差异
  - 适合投资者类型

**交互功能**:
- 拖拽调整对比基金顺序
- 导出对比报告功能
- 保存对比组合供后续查看

#### 4. 风险评估页面 (risk.html)
**功能概述**: 基金风险评估和投资组合风险管理

**主要组件**:
- 风险矩阵图：
  - 横轴：风险（波动率）
  - 纵轴：收益（年化收益率）
  - 基金分布散点图
- 风险指标仪表板：
  - 夏普比率排行
  - 最大回撤统计
  - 波动率分析
- 压力测试工具：
  - 历史情景回测
  - 假设情景分析
  - 风险预警设置
- 投资组合构建器：
  - 基金组合配置
  - 风险分散度分析
  - 预期收益计算

**专业工具**:
- VaR风险价值计算
- 相关性分析矩阵
- 蒙特卡洛模拟

## 技术实现

### 前端技术栈
- **HTML5 + CSS3**: 语义化标签，现代CSS特性
- **Tailwind CSS**: 实用优先的CSS框架
- **JavaScript ES6+**: 现代JavaScript语法
- **核心库**:
  - ECharts.js: 数据可视化
  - Anime.js: 动画效果
  - p5.js: 创意编码
  - Matter.js: 物理动画
  - Splide.js: 轮播组件
  - PIXI.js: 高性能图形

## 用户体验设计

### 视觉层次
1. **主要信息**: 基金名称、净值、收益 - 大字体突出显示
2. **次要信息**: 风险等级、规模、成立时间 - 中等字体
3. **辅助信息**: 详细指标、说明文字 - 小字体

### 色彩编码
- **收益正**: 绿色系 (#38a169)
- **收益负**: 红色系 (#e53e3e)
- **中性信息**: 蓝色系 (#3182ce)
- **警告提示**: 橙色系 (#dd6b20)

### 交互反馈
- 加载状态：骨架屏 + 进度指示器
- 操作反馈：Toast提示 + 状态变化
- 错误处理：友好错误页面 + 重试机制
- 空状态：引导性插图 + 操作建议

## 数据模拟
系统将使用模拟的基金数据，包括：
- 50+只不同类型基金的基本信息
- 历史净值数据和业绩表现
- 持仓结构和行业分布
- 风险指标和评级数据
- 基金经理和管理公司信息

- 静态网站部署，支持本地运行
- 模块化代码结构，便于维护扩展
- 详细的代码注释和文档说明
