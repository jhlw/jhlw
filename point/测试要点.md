## 五、通用缺陷与风险点

| 编号 | 类别 | 严重程度 | 说明 | 涉及文件 |
|------|------|----------|------|----------|
| R-001 | 功能缺失 | 高 | 所有导出按钮仅 `alert()` 占位，无实际文件生成功能 | jizhundianwei |
| R-002 | 功能缺失 | 高 | zhishu.html 搜索/筛选区未绑定事件，查询重置无效 | zhishu |
| R-003 | 功能缺失 | 中 | `queryYieldData()` 仅 `console.log`，未实现实际查询逻辑 | jizhundianwei |
| R-004 | 功能缺失 | 中 | yeji.html "保存草稿"按钮无事件绑定 | yeji |
| R-005 | 功能缺失 | 中 | yeji.html 指数代码选择后名称未自动联动更新 | yeji |
| R-006 | 数据问题 | 高 | 三个文件均使用硬编码静态 JS 对象，无后端 API，刷新丢失所有修改 | 全部 |
| R-007 | 数据问题 | 中 | `queryData()` 使用 `Math.random()` 生成基准点位和收益率，每次查询结果不同 | jizhundianwei |
| R-008 | 编码不一致 | 高 | 中证500：zhishu 用"000905"，jizhundianwei 用"ZZ500" | zhishu + jizhundianwei |
| R-009 | 编码不一致 | 高 | 中债综合财富：zhishu 用"000012"，jizhundianwei 用"ZBZH" | zhishu + jizhundianwei |
| R-010 | 安全问题 | 高 | 多处 `innerHTML` 拼接用户输入（备注、删除原因等），存在 XSS 风险 | 全部 |
| R-011 | 样式问题 | 低 | `.tab-active` 在第33行和第48行重复定义，后者使用 `!important` 覆盖 | jizhundianwei |
| R-012 | 权限问题 | 高 | 无登录态校验，所有操作按钮对所有人可见，审核/确认无权限控制 | 全部 |
| R-013 | 弹窗层级 | 中 | `z-[9999]` 与 `z-[99999]` 混用，嵌套弹窗场景可能层级错乱 | jizhundianwei |
| R-014 | 数据持久化 | 高 | 页面刷新后所有内存数据丢失 | 全部 |
| R-015 | 错误处理 | 中 | 无异常捕获，无网络错误提示 | 全部 |
| R-016 | 表单校验 | 中 | 仅前端校验，部分必填字段使用 HTML5 `required`，可被绕过 | yeji + jizhundianwei |
| R-017 | 浏览器兼容 | 低 | 使用 `classList`、`querySelectorAll`、箭头函数等 ES6+ 特性 | 全部 |
| R-018 | 删除操作 | 中 | zhishu.html 删除弹窗中 `del-btn` 仅打开弹窗，未存储待删除 id，确认删除未实际移除数据 | zhishu |
| R-019 | 权重计算 | 低 | `Number('')` 或 `Number('abc')` 结果为 0，可能误导权重合计 | yeji |
| R-020 | 日期边界 | 低 | `exchangeRateData` 中 `prevWorkday` 与前一日 `current` 不连续（如 10-18 current=7.1836 但 10-20 prevWorkday=7.1905） | jizhundianwei |
