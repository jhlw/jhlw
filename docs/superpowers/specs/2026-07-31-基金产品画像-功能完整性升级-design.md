## 一、背景与目标

### 1.1 当前状态

建信基金产品画像系统现有 7 个 HTML 页面，分为两套视觉体系：

| 页面 | 视觉主题 | 功能状态 |
|------|---------|---------|
| `index.html` | 深色主题 | 系统入口（壳） |
| `compare.html` | 深色主题 | 基金对比（雏形） |
| `analysis.html` | 深色主题 | 分析页（壳） |
| `risk.html` | 深色主题 | 风险分析（壳） |
| `基金产品谱系.html` | 浅色主题（建信品牌色） | 谱系驾驶舱（功能最完整） |
| `基金产品画像.html` | 浅色主题 | 单品画像（仅展示"建信纯债债券A"） |
| `基金产品画像_查询首页.html` | 浅色主题 | 查询首页（15条模拟数据） |

### 1.2 现有问题

- **数据全部硬编码**在 HTML 内联 JS 中，同一基金在多个页面各自维护
- **两个视觉体系并存**，导航断裂，深色主题页面功能空壳
- **缺乏分析深度**：只有"是什么"（展示），没有"为什么"（归因）和"该怎么做"（建议）
- **导出/搜索联动/对比**等功能为占位 `alert()`
- **画像页仅一个产品**：未根据 `fundId` 参数动态渲染

### 1.3 升级目标

为**管理层、投研团队、产品部**三类角色提供从宏观预警到微观归因的完整分析能力：

- **管理层**：智能预警规则引擎 + 趋势预测 + 动态决策建议
- **投研团队**：业绩归因（简化 Brinson） + 持仓穿透 + 风险因子监控 + 经理能力圈
- **产品部**：赛道空白分析 + 时间回溯 + 同业对标

### 1.4 技术方向

采用**轻量数据层架构**（不上框架）：

- 数据：JSON 文件，与视图分离，可独立维护
- 分析逻辑：纯 JS 函数集中在 `analytics.js`，多视图复用
- 图表：ECharts 配置工厂 `charts.js`，消除重复代码
- 路由：基于 hash 的 SPA，单入口 `index.html`
- 部署：纯静态文件，可本地打开或任意 Web 服务器

| 决策 | 说明 |

### 3.1 智能预警引擎

替代现有的静态 `alert-box`，实现规则驱动的动态预警。

#### 预警规则配置（`data/rules.json`）

| 规则 ID | 条件 | 级别 | 建议动作 |
|---------|------|------|---------|
| R01 | 规模 < 2亿 AND 连续3季规模下降 | 🔴 紧急 | 启动转型或清盘评估 |
| R02 | 单季规模降幅 > 30% AND 规模 < 20亿 | 🔴 紧急 | 排查大额赎回原因 |
| R03 | 规模 < 10亿 AND 年度收益同类排名后20% | 🟡 关注 | 评估产品竞争力 |
| R04 | 同一经理管理预警产品 >= 3只 | 🟡 关注 | 评估管理人能力圈匹配度 |
| R05 | 最大单一持有人占比 > 18% | 🟡 关注 | 关注集中度风险 |
| R06 | 赛道仅有 1 只产品 AND 规模 < 5亿 | 🔵 提示 | 考虑增发或合并 |
| R07 | 新发产品成立 6 月内规模 < 2亿 | 🔵 提示 | 评估持续营销必要性 |

- "规则管理"入口可查看/编辑触发条件阈值

#### 实现

### 3.3 决策建议引擎

替代当前写死在 HTML 中的静态 insight-card 文本，由规则引擎动态生成。

#### 生成逻辑

1. 遍历决策建议模板（`data/suggestions.json`）
2. 每条模板包含触发条件（如 `货币占比 > 75%`）
3. 条件满足则渲染对应的建议卡片
4. 优先级排序：紧急 > 关注 > 提示

#### 结构化建议字段

```json

  "title": "货币占比过高",
  "body": "货币类占比 {moneyRatio}%，为银行系最高。建议一年内通过固收+产品将占比降至 75% 以下。",
  "action": { "text": "查看固收+产品线", "route": "#/product/track/固收+" }
}
```

## 四、投研视图 — 业绩归因 + 持仓穿透 + 风险监控

### 4.1 业绩归因分析（全新模块）

采用简化 Brinson 归因法，将债券基金收益拆解为四个因子：

**收益 = 票息贡献 + 久期贡献 + 曲线贡献 + 择券贡献**

| 因子 | 计算方式 | 含义 |
|------|---------|------|
| 票息贡献 | 持仓加权票息 × 时间 | 持有到期的固定收益 |
| 久期贡献 | 组合久期变动 × 基准利率变动 | 利率方向性判断的收益 |
| 曲线贡献 | 久期中性下的曲线变平/变陡收益 | 收益率曲线形态押注 |
| 择券贡献 | 总收益 − 以上三项 − 费率 | 信用挖掘和个券选择α |

#### 实现

```javascript
// analytics.js — 纯函数，可独立测试
function computeAttribution(product) → {coupon, duration, curve, selection, residual}
```

#### 可视化

- 水平堆叠条形图，正负值用绿/红色
- 与同类 TOP5 均值对比标注
- 自动生成归因结论文字

### 4.2 持仓穿透（升级现有"前五大重仓债券"）

现有画像页仅有"前五大重仓债券"列表。升级为三维可视图：

- **信用评级分布**（环形图）：AAA/AA+/AA/现金
- **行业分布**（柱状图）：利率债/金融债/城投债/产业债/中票
- **久期结构分布**（柱状图）：<1年 / 1-3年 / 3-5年 / >5年
- **杠杆率趋势**（折线图）：近 8 季度变化

### 4.3 风险因子监控（升级现有静态指标表）

现有画像页用表格罗列波动率、夏普等指标，缺少关联分析。升级为：

- **风险热力图**：近 12 个月 × 4 个维度（信用风险、利率风险、流动性风险、集中度风险），🟢🟡🔴 三色标注
- **变动解释**：自动标注指标变化的原因（如"久期从 2.5→2.8 年，导致利率风险上升"）
- **同业对比条**：每个风险维度在产品 vs 同类均值之间用横向进度条对比

### 4.4 基金经理能力圈分析（升级现有静态经理卡片）

现有画像页已有经理详情，升级为：

- **擅长赛道雷达图**：利率债 / 信用债 / 可转债 / 短久期 / 长久期，各维度 0-100 评分
- **同类经理排名**：各维度的同类分位值
- **在管产品关联图谱**：树状结构展示经理管理的所有产品及规模
- **自动评价文字**：基于数据生成能力评价总结

## 五、产品部视图 — 赛道分析 + 时间回溯 + 同业对标

### 5.1 赛道空白分析（升级现有策略覆盖度表格）

现有谱系页面标注了"商品/黄金ETF 空白"，但仅为静态文本。升级为动态四象限分析：

- **X 轴**：公司覆盖度（已布局产品数 / 赛道理论容量）
- **Y 轴**：行业规模增速（近一年该赛道总规模增长%）
- **气泡大小**：赛道总规模
- **颜色**：🟢 强覆盖 / 🟡 弱覆盖 / 🔴 空白
- **结论生成**：自动推荐优先布局赛道

#### 实现

```javascript
// analytics.js
function analyzeTrack(products, industryData) → [{track, coverage, growth, quadrant, recommendation}]
```

### 5.2 时间回溯（全新模块）

为产品部提供"回到过去"的谱系快照。

- **时间点选择**：下拉选择历史季度（如 `2025Q2`、`2024Q2`）
- **快照对比表**：并列展示多个季度的关键指标（总规模、货币占比、权益规模、小微基金数、产品总数等）
- **变化追踪**：自动标注显著变化（如"小微基金从 8 只升至 12 只，增幅 +50%"）

#### 数据基础

`data/history/` 目录下存放至少 8 个季度的完整快照 JSON 文件。

### 5.3 同业对标（升级现有静态排名表格）

现有页面已有排行数据，升级为：

- **对标公司选择**：可勾选 2-4 家竞品公司
- **蜘蛛图对比**：多维指标（规模/权益/固收/渠道多样性/费率效率）并行展示
- **差异解读**：自动生成文字对比说明（如"建信规模靠货币，招商规模靠固收+权益"）

### 6.3 页面加载流程

```
index.html 加载
  → data.js 加载 JSON 文件（带 localStorage 缓存，T+1 失效）
  → router.js 解析 hash，确定当前视图
  → 按需渲染对应视图模块
  → 各模块调用 analytics.js 做计算
  → 各模块调用 charts.js 渲染图表
  → filter.js 处理搜索/筛选/排序交互
  → ui.js 提供 Toast/Modal/Tab 等通用组件
```
