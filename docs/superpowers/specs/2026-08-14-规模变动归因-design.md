# 规模变动归因界面原型设计方案

- 日期：2026-08-14
- 角色：需求分析人员（基金公司内部）
- 状态：已评审通过（会话内分节确认）
- 隶属子项目：产品画像（`产品画像/`），与《2026-08-14-产品谱系与产品画像-design.md》同源

## 1. 背景与定位

产品画像平台已定稿三屏原型（公司画像速览页、产品谱系页、产品画像页）。产品画像页中的「规模走势」卡片只展示净资产曲线，无法回答"规模为什么变"：是净值（业绩）驱动，还是份额（申赎）驱动。

本模块为平台**新增的第四个界面原型**：以图表展示基金产品的规模变动、净值变动、份额变动，并用归因分解直观呈现**净值与份额各自对规模变动的影响程度**。

- **交付形态**：独立单文件 HTML 原型（`产品画像/prototypes/规模变动归因原型.html`），零依赖，视觉延续三屏原型（纯内联 SVG + CSS 变量 + 原生 JS）
- **实例产品**：建信恒久价值混合 A（530001），与产品画像页 v16 同一实例。其特征"净值缓涨 + 份额持续赎回 → 规模缩水"是展示双因素对冲的天然教材
- **读者**：内部为主（产品经理/投研季度复盘，信息密度高、含术语与公式），同页 JS 切换销售变体（渠道/客户沟通，通俗化）

## 2. 归因口径（数学底座）

恒等式：**规模（净资产）= 单位净值 × 份额**，示例数据每季度严格满足。

区间变动采用**对数分解**，精确可加、无交互残差：

```text
ln(S₁/S₀) = ln(N₁/N₀) + ln(Q₁/Q₀)
规模对数变动 = 净值对数变动 + 份额对数变动
贡献占比 = 各侧对数变动 ÷ 规模对数变动（占比之和恒为 100%）
贡献额 = 贡献占比 × 区间规模变动额（S₁ - S₀）
```

约定：

- 贡献占比与贡献额均带符号：净值上涨、份额申购为正贡献，净值下跌、份额赎回为负贡献
- 界面脚注注明口径公式与「贡献占比之和 = 100%」的校验说明
- 贡献额因四舍五入与精确值存在 ±0.1 亿级误差，脚注注明

## 3. 页面结构（自上而下）

| # | 区块 | 说明 |
| --- | --- | --- |
| 1 | 页头 | 模块名「规模变动归因」+ 产品标识条（名称/代码/谱系编码/银河分类）+ 视图切换按钮（内部/销售） |
| 2 | 指标卡行 | 内部视图 6 卡：最新规模、最新净值、最新份额、区间规模变动、区间净值贡献、区间份额贡献；后 3 卡随所选区间联动。销售视图精简为 4 卡（最新规模、最新净值、区间业绩贡献、区间申赎贡献） |
| 3 | 三线趋势图 | 规模/净值/份额指数化（区间起点=100）三线；hover 十字线 + tooltip 三线实值；下方区间选择器（预置近 1/2/3 年 + 双滑块拖选） |
| 4 | 归因条（核心） | 所选区间规模变动分解：正贡献向右、负贡献向左，净值贡献（绿）、份额贡献（红），长度∝贡献额绝对值；贡献占比标注；配一句话结论卡。本例净值贡献恒正（向右）、份额贡献恒负（向左） |
| 5 | 各季贡献堆叠柱 | X=14 个季度，上正下负；绿=净值贡献、红=份额贡献，柱高=该季规模变动 |
| 6 | 口径脚注 | 对数分解公式、数据来源（季报，季度更新）、示例数据标注（与三屏原型口径一致） |

## 4. 图表规格

### 4.1 三线趋势图

- 指数化：所选区间起点三线均 =100，Y 轴为指数值；tooltip 显示实值（规模亿元 / 净值元 / 份额亿份）
- 三线颜色延续现有 CSS 变量体系（经 dataviz CVD 校验）：规模=品牌蓝带内版 #1A56A8（--ccb #003399 亮化）、净值=原型既有橙 #E08A3C、份额=中蓝 #2E6FD1（虚线二级编码）；图例区分实线/虚线
- 默认选中区间：近 3 年（12 季度）

### 4.2 归因条（区间规模变动分解）

- 水平双向条形：零轴居中，净值贡献向左或向右取决于符号，份额贡献同理；条长∝|贡献额|，两端标贡献额与占比
- 结论卡：一句话自动生成，如「规模缩水主要由份额赎回驱动（份额贡献 -117%），净值上涨对冲 +17%」；销售视图结论口语化（「规模下降主要因为投资者赎回，产品业绩其实在涨」）
- 结论句式覆盖四种组合：双正 / 双负 / 净值正+份额负 / 净值负+份额正

### 4.3 各季贡献堆叠柱

- X 轴 14 个季度标签（2023Q1–2026Q2），Y 轴贡献额（亿元），零轴上方净值贡献（绿）、下方份额贡献（红）
- hover 显示该季明细：规模变动、净值贡献、份额贡献及三者校验和

## 5. 双视图变体（同页 JS 切换）

| 差异点 | 内部视图 | 销售视图 |
| --- | --- | --- |
| 术语 | 净值贡献 / 份额贡献 | 业绩贡献 / 申赎贡献 |
| 结论卡 | 含占比数据 | 口语化一句话，放大显示 |
| 公式脚注 | 显示对数分解公式 | 隐藏，改为通俗说明 |
| 产品标识 | 名称/代码/谱系编码/银河分类 | 仅名称/代码 |
| 指标卡 | 6 卡 | 4 卡 |

## 6. 交互规格

| 交互 | 行为 |
| --- | --- |
| 视图切换 | 按钮切换内部/销售：术语替换、公式脚注显隐、指标卡 6→4、结论卡文案切换 |
| 区间选择 | 预置按钮（近 1/2/3 年/全部）+ 趋势图下方双滑块拖选；指标卡后 3 卡、归因条、结论卡同步重算 |
| 趋势图 hover | 十字线 + tooltip 显示三线该季实值 |
| 贡献柱 hover | tooltip 显示该季分解明细 |
| 归因条 hover | 高亮对应贡献段 |

所有重算基于第 2 章口径即时计算，不预存多组静态结果。

## 7. 示例数据

- 区间 2023Q1–2026Q2 共 14 个季度，数据标注「示例」
- 真实锚点（与产品画像页⑨⑧一致）：2026Q1 末单位净值 1.0235、2026-02-06 净值 1.0757、2025 年末净资产 8.68 亿、成立 62.02 亿份
- 趋势设定：净值从 ~0.85 缓涨至 ~1.03（净值贡献恒正）；份额从 ~19 亿份持续赎回至 ~8.8 亿份（份额贡献恒负）；规模从 ~16 亿缩至 ~9 亿
- 构造规则：每季度 S = N × Q 精确成立（N 取 4 位小数、Q 取 2 位、S 取 2 位）

## 8. 技术约束

- 单 HTML 文件，无外部依赖（不引 ECharts/CDN），与现有三屏原型一致
- 图表用内联 SVG + 原生 JS 渲染/重算；CSS 变量沿用现有体系，新增归因语义色（经 dataviz CVD 校验）：净值贡献=绿 #1B873B、份额贡献=红 #D92D20，配方向（正右负左）+ 文字标签双重编码
- 编码与注释简体中文；文件提交遵循 Conventional Commits

## 9. 非目标

- 不做真实数据接入（数据为示例，锚点真实）
- 不改造既有三屏原型（本模块为独立原型文件；并入产品画像页属后续规划）
- 不做同业/多产品对比归因（仅单产品纵向归因）
- 不做交互项（ΔN×ΔQ）残差展示（对数分解已无残差）
