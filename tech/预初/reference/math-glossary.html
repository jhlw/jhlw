基础概念

术语定义月考陷阱
自然数 0, 1, 2, 3, …（非负整数） 0是自然数！（现行教材规定，判断题常考）
正整数 1, 2, 3, …（大于0的整数） 最小正整数是1，没有最大
整数 …, -2, -1, 0, 1, 2, … "整数就是自然数"→错（含负整数）
整除 整数a ÷ 非零整数b = 整数商且余数为0 三个条件缺一不可；记作 b ∣ a
除尽 除法运算余数为0（不要求整数） 整除 ⊂ 除尽；"凡是能除尽的算式都是整除"→错！

因数与倍数

术语定义月考陷阱
因数（约数） 若 a ÷ b = c（整数），则 b 和 c 是 a 的因数 "10是倍数，2是因数"→错！要说清谁是谁的
倍数 若 a 能被 b 整除，则 a 是 b 的倍数 倍数和因数是相互依存的
公因数 几个数共有的因数 1是所有正整数的公因数
最大公因数 公因数中最大的一个，记作 (a, b) 求法：短除法 / 分解素因数法
公倍数 几个数共有的倍数 最小公倍数记作 [a, b]
最小公倍数 公倍数中最小的正整数 核心公式：(a,b) × [a,b] = a × b
互素（互质） 两个数的最大公因数为 1 "两个合数一定不互素"→错（8和9互素）

数的分类

术语定义月考陷阱
奇数 不能被2整除的整数 负数也可以是奇数（-1, -3...）
偶数 能被2整除的整数 0是偶数！
素数（质数） 大于1，只有1和本身两个因数 2是唯一的偶素数；最小的素数是2
合数 大于1，除了1和本身还有别的因数 最小的合数是4；最小的奇数合数是9
1 既不是素数也不是合数 判断题最高频考点之一！
分解素因数 把一个合数写成素数乘积的形式 用短除法；结果从小到大的顺序写
素因数 一个数的因数中的素数 28的素因数是2和7（不是2, 4, 7, 14, 28）

整除判定法则

除数判定方法速记
2末位是偶数（0,2,4,6,8）看最后一位
3各位数字之和能被3整除⚡最高频考点
5末位是0或5看最后一位
2和3偶数 + 各位数字之和是3的倍数即能被6整除
3和5末位0或5 + 各位数和是3的倍数即能被15整除
2和5末位是0即能被10整除

本课新增：同余问题方法

题型方法关键步骤
一个数除多个数余数相同 差值法 求两两差值 → 差值的最大公因数 = 答案
一个数被多个数除余数相同 LCM + 余数 求LCM → 答案 = LCM × k + 余数
