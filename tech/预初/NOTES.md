# 教学笔记

## 学生画像
- 预初新生（即将入读张江集团中学）
- 数学：校内基础尚可，未学过奥数/思维训练，需要从基础概念系统搭建
- 英语：未系统学过新概念等课外内容，词汇和语法需要从基础补起
- 语文：相对放心，保持日常积累即可

## 教学偏好
- 教学对象是家长（家长辅导孩子），课程内容需要适合家长理解后转教
- 课程应包含：核心知识点 → 例题讲解 → 练习（含答案）
- 数学优先，英语次之，语文保持
- 练习题难度需对齐张集实际水平（诊断练习一均分约60，阶段练习一同样难）

## 张集9月月考实际情况（据公开信息）
- **诊断练习一**：纯数的整除，100分/90分钟，均分≈60
  - 判断题（10×1）— 概念辨析陷阱多
  - 填空题（15×2）— 计算+推理
  - 选择题（3×3）— 概念理解
  - 简答题（3×6）— 短除法分解素因数、求GCD/LCM
  - 解答题（6题共33分）— 含新定义题型
- **阶段练习一**（约9月22日）：整除 + 分数，同样难
- 特色题型：新定义题（无暇素数/牛牛数/幸运数/加成分数等）

## 课程设计原则
- 每节课聚焦一个紧密的知识点
- 知识点先行，紧接着技能练习
- 练习题必须对标张集难度，包含：
  - 概念辨析题（判断题高频陷阱）
  - 真题改编题
  - 1道新定义/思维拓展题（选做）
- 答案分"基础步骤"和"详细解析"两层

## 数学课程路线图
```
第1课  整除的定义与条件 + 整除特征（被2/3/5整除）
第2课  素数、合数与分解素因数
第3课  公因数与最大公因数
第4课  公倍数与最小公倍数
第5课  整除综合 + 新定义题型专项
第6课  分数基础（真分数/假分数/约分通分/比较大小）
第7课  分数四则运算
第8课  分数应用题
第9课  有理数初步（数轴/相反数/绝对值）
...
```
