# 分层考试时间线与考试体系确认

通过搜索确认了张江集团中学预初阶段的分层评估体系。与最初假设不同：分班不是由单次入学考试决定的，而是通过一套渐进式的评估体系（9月月考 → 期中 → 11月分层考），综合评定后分A/B层。

**Why this matters**: 这意味着准备时间比最初预想的更长（约2.5-3个月而非几周），暑假可以系统打基础而非突击刷题。同时也意味着开学后的每次考试都计入分层评估，不能只抓一次。

**Implications**:
- 暑假策略：系统预习第一单元（数的整除）+ 补齐小初衔接缺口（有理数、方程）
- 开学策略：紧跟校内进度，确保周爽稳定发挥
- 英语和语文也有更充裕的时间做积累
